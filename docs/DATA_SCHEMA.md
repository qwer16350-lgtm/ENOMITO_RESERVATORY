# Data Schema v0.1

시드의 출처는 다마고치입니다. 확정된 인계 스키마와 실제 인계 파일은 아직 제공되지 않았습니다.

다음 단계에서 schemaVersion, 원본 개체 식별자, 인계 시각, 미토 상태 및 성장 이력의 필수 항목과 허용 범위를 합의합니다. 이는 제안 항목이며 확정 계약이 아닙니다. 외부 데이터는 검증 후 내부 World State로 변환합니다. Renderer는 원본 데이터를 직접 수정하지 않습니다.

임시 프로필 모델은 name, arrivedAt(Unix 밀리초), type, generation입니다. 실제 인계 계약은 아직 확정되지 않았습니다. 데모는 미토/기본형/1세대이며 arrivedAt은 화면 시작 시각입니다. 저장하지 않아 새로고침 시 초기화됩니다. 나이는 출생 나이가 아니라 관측소 도착 후 경과 시간입니다.
