# Windows 개발환경 구성 기록

검증일: 2026-10-03 (한국 시간)

기존에는 Codex 내부용 Node.js 24.19.0과 Git 2.53.0.windows.3만 확인되었습니다. Windows 설치 목록과 표준 설치 경로에서 Node.js, Git, VS Code는 확인되지 않아 공식 winget 패키지로 설치했습니다.

| 도구 | 설치 및 확인 버전 |
| --- | --- |
| Node.js LTS | 24.19.0 |
| npm | 11.17.0 |
| Git | 2.55.0.windows.5 |
| VS Code (현재 사용자) | 1.140.0 |
| Vite | 8.3.2 |
| TypeScript | 7.0.2 |
| Phaser | 4.2.1 |

- 이 폴더에 main 브랜치로 Git 저장소를 초기화했습니다.
- 초기에는 글로벌 Git 설정 파일이 없었습니다. 이후 GitHub 연결 과정에서 사용자가 제공한 이름과 이메일을 이 저장소의 로컬 설정에 등록했습니다.
- npm 패키지와 package-lock.json을 생성했습니다. 이후 재현 설치는 npm.cmd ci를 사용합니다.
- npm.cmd run check 및 npm.cmd run build가 통과했습니다.
- npm 의존성 검사에서 알려진 취약점은 0개였습니다(설치 시점 기준).
- http://127.0.0.1:5173 에서 타일 화면과 'Phaser 실행 정상 · 시드 데이터 미주입' 표시를 브라우저로 확인했습니다.
- Phaser를 포함한 약 1.38 MB(압축 약 358 KB) JavaScript 번들로 인해 크기 경고가 있습니다. 빌드는 성공했으며 실제 배포 단계에서 분할 전략을 검토합니다.
- 설치 관리자가 필요한 표준 설치 및 경로 등록을 수행했습니다. PowerShell 실행 정책과 방화벽은 변경하지 않았습니다. 이후 GitHub 연결 과정에서 폴더 소유자 차이로 발생하는 Git 경고를 해결하기 위해 이 프로젝트의 정확한 경로만 글로벌 safe.directory에 등록했습니다.
- winget 설치 목록 조회 중 Microsoft Store 원본 계약이 수락되었습니다. 실제 설치는 winget 원본만 사용했습니다.
- 동기화된 sources/ 파일은 변경하지 않았습니다. 게임 행동, 저장, 푸시 알림, 배포 및 실제 시드 데이터 주입은 이번 범위에 포함되지 않습니다.

설치 후 열려 있던 터미널은 새로 열어야 새 PATH가 반영될 수 있습니다. Codex 세션에서는 기존 내부 런타임이 우선될 수 있어 설치된 도구의 절대 경로로도 버전을 확인했습니다.
