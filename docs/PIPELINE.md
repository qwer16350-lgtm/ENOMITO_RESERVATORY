# Development Pipeline v0.1

미니맵은 게임 화면 좌측 하단에 고정됩니다. 전체 1024×1024 맵을 동일한 아이소메트릭 방향의 다이아몬드로 축약하며, 카메라 bounds를 같은 비율로 변환해 흰 테두리 사각형으로 표시합니다. 캐릭터 발 WORLD 좌표는 투영 후 형광 초록 점으로 표시합니다. 카메라가 정지해도 캐릭터 위치는 매 프레임 갱신합니다. 현재는 균일한 임시 지형이므로 미니맵도 균일한 지형 표시이며 미니맵 다이아몬드 안을 클릭하면 해당 위치로 카메라가 즉시 이동합니다. SVG 화면 변환을 역변환해 크기 변화와 페이지 스크롤에도 클릭 좌표를 맞춥니다. 다이아몬드 밖의 여백 클릭은 무시합니다. 기존 확대율을 유지하고 이동 관성/가장자리 이동은 중단합니다. 카메라 중심은 유효 맵 경계 안으로 제한합니다.

1. 작업 범위와 데이터 계약을 먼저 확인합니다.
2. 데이터 → World State → Simulation → Renderer 흐름을 유지합니다.
3. core/world/entities/behavior/events/camera/ui/save의 책임을 분리합니다.
4. GRID 주소, 연속 WORLD 좌표, 투영 ISOMETRIC 픽셀, 카메라 적용 SCREEN 픽셀을 구분합니다.
5. 변경 후 npm run check, npm test 및 npm run build를 수행하고 npm run dev로 화면을 확인합니다.
6. 새 규격과 변경 사항을 docs에 함께 기록합니다.

맵은 1024×1024타일(1,048,576칸), 유효 GRID 주소는 각 축 0~1023입니다. 균일한 임시 지형을 사용하며 전체 개체 배열을 만들지 않습니다. 카메라 사각형을 역투영해 후보 범위를 계산한 뒤 화면과 겹치는 타일만 그립니다. 카메라가 변경될 때만 그리기 명령을 갱신합니다. 기존 코드 도형과 32칸 간격 표시선은 잔디 PNG 타일 에셋으로 대체했습니다. TerrainRenderer가 화면에 필요한 이미지 개체만 재사용하며 표시 크기는 64×32입니다.

맵 화면 안쪽 가장자리 40 CSS 픽셀에 마우스를 두면 해당 화면 방향으로 이동합니다. 클릭은 필요하지 않습니다. 가장자리에 가까울수록 빨라지며 최대 속도는 초당 600 게임 화면 픽셀입니다. 대각선 속도를 정규화하고 프레임 시간으로 이동량을 계산합니다. 커서가 중앙/맵 밖으로 이동하거나 창의 포커스를 잃으면 정지합니다. 마우스/터치 드래그도 지원합니다. 드래그 중에는 가장자리 이동을 일시 중단하고, 놓으면 마지막 이동 속도로 관성이 이어지며 지수 감쇠합니다. 멈춘 상태로 100ms 이상 기다렸다 놓으면 관성을 시작하지 않습니다. 관성 중 맵을 누르는 즉시 속도를 0으로 만들고, 클릭만 한 경우 정지 상태를 유지합니다. 맵 경계, 포커스 상실, 포인터 취소, 확대/중심 복귀 조작도 관성을 정지시킵니다.

휠/버튼 확대(0.5~3배), 중심 복귀를 지원합니다. 카메라 중심을 맵의 유효 WORLD 범위 안으로 제한합니다. 맵 모서리에서 화면에 배경이 보일 수 있습니다. 초기 카메라는 맵 중앙을 봅니다. 저장, 알림, PWA 및 실제 시드 주입은 아직 구현하지 않았습니다.

맵 중앙에서 생성되는 임시 캐릭터 하나는 휴식(1~5초)과 무작위 목적지 이동(2~10타일)을 반복합니다. 속도는 월드 기준 초당 1.2타일입니다. WanderBehavior가 모델 상태와 WORLD 위치를 갱신하고 Renderer가 위치, 깊이, 스프라이트를 동기화합니다. 이동 벡터를 투영한 화면 방향으로 8방향 이미지를 매칭하며 휴식 시 N/NE/NW 이동 뒤에는 후면(N), S/SE/SW 이동 뒤에는 정면(S)으로 정지합니다. E/W 이동 뒤에는 가장 최근의 정면·후면 구분을 유지하며 초기 기본값은 정면입니다. 카메라와 독립적으로 맵 전체에서 시뮬레이션하고 맵 경계를 지킵니다. 탭이 숨겨지면 시뮬레이션을 일시 정지합니다. 충돌/길찾기/저장은 아직 없습니다. 한 개체의 이동 방향에 따라 기존 8개 이미지를 전환합니다. 휴식 시 직전 정면·후면 계열에 따라 S 또는 N 이미지로 정지하고 이동 시 같은 이미지에 작은 흔들림을 적용합니다. 실제 걷기 프레임 애니메이션은 추후 교체합니다. 실제 다마고치 시드와는 별개입니다. 교체 규격은 ASSET_GUIDE.md를 따릅니다.

캐릭터 마우스 오버 시 프로필 말풍선을 표시합니다. 이름, 도착 후 경과 시간(시간/분), 유형, 세대를 표시하며 카메라 좌표와 CSS 크기를 반영해 캐릭터를 가리킵니다. 드래그 또는 커서 이탈 시 숨기며 위쪽 공간이 부족하면 아래쪽으로 표시합니다.

프로필의 세대 아래 행동 행에서 현재 이동/휴식 상태를 실시간 표시합니다. 캐릭터 아래 라벨은 프로필 이름을 표시하며 프로필이 없으면 개체 ID를 사용합니다.

미니맵 우측 상단 −/+ 버튼으로 최소화/펼치기를 전환합니다. 최소화 시 제목과 버튼만 남으며 키보드 Enter/Space로도 조작합니다. 펼치면 최신 카메라와 캐릭터 위치를 표시합니다. 접힘 상태는 새로고침 시 초기화됩니다.
M 키는 미니맵 접기/펼치기를 전환하며 키 반복, 입력 필드, 한글 조합 중, Ctrl/Alt/Meta 조합은 무시합니다. 범례 캐릭터 버튼은 현재 스프라이트 중심으로 카메라를 한 번 이동시키고 확대율을 유지하며 관성/가장자리 이동을 중단합니다. 지속 추적은 하지 않습니다.
캐릭터 스프라이트를 더블클릭하면 300% 이외의 배율에서는 300%, 300%에서는 100%로 전환합니다. 클릭한 캐릭터 중심으로 카메라를 맞추며 관성/가장자리 이동을 중단합니다. 빈 맵 더블클릭은 배율을 변경하지 않습니다.

잔디 5종은 공통 경계색으로 연결되며 WORLD 주소 기반 해시로 드문 장식 타일을 섞습니다. 화면 타일만 재사용하는 렌더링을 유지합니다. 세부 비율과 텍스처 규격은 ASSET_GUIDE.md를 따릅니다.
NatureWorld는 32칸 청크를 지연 생성하고 위치 질의를 담당합니다. 나무 배치는 결정적이며 큰 나무는 주변 6타일 이상 이격됩니다. NatureRenderer는 보이는 나무만 재사용하고 밑동 깊이로 캐릭터와 정렬합니다. WanderBehavior는 이동 경로를 최대 0.05타일 간격으로 검사하고 충돌 시 기존 목적지를 버리고 빈 방향으로 즉시 이탈합니다. 완전히 막히면 대기 후 재시도합니다. 길찾기는 아직 구현하지 않았습니다.
미토가 나무보다 뒤쪽이고 겹칠 때 나무의 미토 실루엣 영역만 alpha 50%로 표시합니다. 나머지 나무는 불투명합니다. 이동/방향/카메라 변화에 맞춰 갱신하며 겹침이 끝나면 원본 텍스처로 복원합니다. 충돌 규칙은 유지합니다.


큰 나무 전체 회전은 제거하고 아래의 미세한 밑동 기준 회전만 적용합니다. LeafWind가 색상/위치/가로 폭으로 잎과 가는 상단 가지를 분리해 작은 부분 움직임을 만듭니다. 잎 프레임 내부에서 굵은 가지, 줄기, 밑동과 뿌리는 원래 픽셀 위치를 유지하며, 전체 이미지는 고정 밑동을 중심으로 미세하게 회전합니다. 종류별 72개의 작은 프레임을 공유하고 보이는 나무만 전환합니다. 가림 마스크는 프레임 변경 시 갱신합니다.

반투명 캔버스는 실제 크기가 달라질 때만 재설정합니다. 마스크 갱신은 최대 30Hz로 제한하고 캐릭터 위치를 나무 텍스처 픽셀 단위로 비교해 불필요한 GPU 업로드를 줄입니다. 잎 프레임 전환 속도도 조정했습니다. canvas.dataset.fps/slowFrames로 최근 1초 평균 FPS와 33ms 초과 프레임 수를 확인할 수 있습니다.

잎의 세로 분할 위상은 연속 위상으로 바꾸고 이동폭을 텍스처 기준 ±0.20px로 줄였습니다. 역방향 샘플링과 원본 수관 커버리지 유지로 잎 묶음 사이 빈 줄을 방지합니다. 색상 사이의 작은 보간으로 72개 프레임을 세분화하며 굵은 목질부는 고정됩니다.


잎은 72개의 공유 프레임을 최대 30Hz로 전환해 단계감을 줄입니다. 나무 전체는 밑동 기준 ±0.10도, 약 12~15초 주기의 좌우 움직임을 매 렌더 프레임 연속 계산합니다. 이전의 큰 회전과 달리 최상단도 대략 1px 이내로 움직입니다. 가림 마스크 키에 미세 회전을 반영합니다.




미니맵 나무는 실제 NatureWorld 배치를 짙은 초록색(#123c24) 점으로 표시합니다. 크기에 따라 점 크기를 구분하며, 전체 배치를 한 번 래스터화해 공유합니다. 원거리 시뮬레이션 청크는 이 과정에서 캐시에 보관하지 않습니다. 캐릭터와 카메라 표시는 나무 위에 유지합니다.

방향키는 화면 기준 8방향으로 미토를 직접 이동시킵니다. 대각선 속도는 정규화하며 자동 배회와 같은 속도를 사용합니다. 수동 조작 중 나무/맵 경계 앞에서 멈추고 키를 놓으면 정면/후면 휴식 후 자동 배회를 재개합니다. 포커스 상실/탭 숨김 시 키 상태를 초기화합니다.
Shift와 방향키는 3.6타일/초로 달립니다. 충돌 검사를 유지하며 6방향 전용 4프레임 모션과 260ms 안에 사라지는 alpha 48% 먼지를 사용합니다. 먼지는 16개를 재사용합니다.

미토가 나무 밑동 충돌 경계에 닿으면 머리 위에 픽셀 말풍선과 4단계 도끼 들썩임을 표시합니다. 접촉이 끝난 뒤 0.5초간 유지해 순간 접촉도 보이게 합니다. 나무 제거/벌목 기능은 추가하지 않습니다.
도끼 말풍선은 중심 기준 160ms ease-out 확대, 130ms 가속 축소로 등장/퇴장합니다. 도끼도 같은 비율로 함께 전환하고 완전히 펼친 크기는 유지합니다. 전환 도중 재접촉 시 현재 크기에서 역전해 튀지 않도록 합니다.
접촉 말풍선과 도끼는 함께 2초 주기로 위아래 총 3px(중심에서 ±1.5px) 둥실거립니다. 등장/퇴장 중심도 같은 위치를 따릅니다.
전역 조명 표현은 WorldLighting의 공통 환경광 tint와 좌상단 광원/우하단 지면 그림자로 통일합니다. 물리 기반 GI나 실시간 광선 추적은 사용하지 않습니다. 나무 그림자는 종류별 정적 실루엣 텍스처 5개를 시작 시 생성하고 보이는 개체에 재사용합니다. 밑동 접촉 음영과 미토 지면 그림자는 공통 텍스처를 공유합니다. 그림자는 지형 위/개체 아래에 표시하고 기존 수관 반투명 처리와 독립적입니다.
바람 효과 갱신: 잎 변위 ±0.20→±0.30 텍스처px(50% 증가), 밑동 기준 본체 회전 ±0.0018→±0.0054rad(3배). 나무 그림자도 동일한 잎 프레임과 본체 위상을 사용하며 압축된 지면 투영 기준으로 회전폭을 환산합니다. 그림자 프레임은 종류별 공유 72개를 미리 생성해 런타임 재생성을 피합니다.

나무 렌더링을 목질부/잎의 독립 텍스처와 이미지로 분리했습니다. tree-wood는 고정 픽셀 형태에 밑동 기준 강체 회전만 적용하며 tree-leaves 프레임에는 목질부 픽셀이 없습니다. 두 레이어 모두 캐릭터 가림 마스크를 적용합니다. 원본 합성 PNG는 보존하고 시작 시 분리된 런타임 에셋을 생성합니다. 그림자는 분리 전 합성 프레임을 사용합니다.
목질부는 연속 회전을 제거했습니다. 밑동 고정 5자세(-2..2px) 텍스처를 미리 생성하며 높이에 따른 정수 픽셀 이동만 사용합니다. RGB/alpha 보간은 없고 동일 주기로 자세를 전환합니다. 잎의 효과는 유지합니다.
목질부의 5단계 전환을 65개의 중간 자세(1/16 텍스처px 간격)로 세분화했습니다. 밑동은 고정하고 나무 RGB 팔레트는 보간하지 않습니다. 외곽 alpha coverage만 보간해 이동 단계감을 줄입니다. 완전한 정수 픽셀 방식보다 외곽이 약간 부드러워지는 절충입니다.
목질부의 행별 변위/중간 자세 생성은 제거했습니다. tree-wood 한 장을 origin (0.5,1), 즉 밑동 중심에서 통째로 좌우 회전합니다. 목질부 픽셀 좌표나 alpha를 프레임마다 변형하지 않습니다. 잎 효과와 그림자 위상은 유지합니다.
목질부의 픽셀 격자 일렁임을 피하기 위해 목질부는 회전 없이 고정합니다. 나무 종류/배율별 예외는 추가하지 않습니다. 잎의 미세 회전/물결과 그림자 움직임은 유지합니다. 목질부의 물리적 흔들림은 현재 비활성화됩니다.
목질부의 밑동 기준 회전을 다시 활성화하고 목질부 텍스처에만 LINEAR 필터를 적용합니다. 가림용 목질부 캔버스도 같은 필터를 사용합니다. 잎 텍스처와 가림용 잎 캔버스는 NEAREST를 유지합니다. 목질부 가장자리는 약간 부드러워집니다.
