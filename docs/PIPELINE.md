# Development Pipeline v0.1

미니맵은 게임 화면 좌측 하단에 고정됩니다. 전체 1024×1024 맵을 동일한 아이소메트릭 방향의 다이아몬드로 축약하며, 카메라 bounds를 같은 비율로 변환해 흰 테두리 사각형으로 표시합니다. 캐릭터 발 WORLD 좌표는 투영 후 형광 초록 점으로 표시합니다. 카메라가 정지해도 캐릭터 위치는 매 프레임 갱신합니다. 현재는 균일한 임시 지형이므로 미니맵도 균일한 지형 표시이며 미니맵 다이아몬드 안을 클릭하면 해당 위치로 카메라가 즉시 이동합니다. SVG 화면 변환을 역변환해 크기 변화와 페이지 스크롤에도 클릭 좌표를 맞춥니다. 다이아몬드 밖의 여백 클릭은 무시합니다. 기존 확대율을 유지하고 이동 관성/가장자리 이동은 중단합니다. 카메라 중심은 유효 맵 경계 안으로 제한합니다.

1. 작업 범위와 데이터 계약을 먼저 확인합니다.
2. 데이터 → World State → Simulation → Renderer 흐름을 유지합니다.
3. core/world/entities/behavior/events/camera/ui/save의 책임을 분리합니다.
4. GRID 주소, 연속 WORLD 좌표, 투영 ISOMETRIC 픽셀, 카메라 적용 SCREEN 픽셀을 구분합니다.
5. 변경 후 npm run check, npm test 및 npm run build를 수행하고 npm run dev로 화면을 확인합니다.
6. 새 규격과 변경 사항을 docs에 함께 기록합니다.

맵은 1024×1024타일(1,048,576칸), 유효 GRID 주소는 각 축 0~1023입니다. 균일한 임시 지형을 사용하며 전체 개체 배열을 만들지 않습니다. 카메라 사각형을 역투영해 후보 범위를 계산한 뒤 화면과 겹치는 타일만 그립니다. 카메라가 변경될 때만 그리기 명령을 갱신합니다. 32칸 간격의 밝은 선은 위치 파악용입니다.

맵 화면 안쪽 가장자리 40 CSS 픽셀에 마우스를 두면 해당 화면 방향으로 이동합니다. 클릭은 필요하지 않습니다. 가장자리에 가까울수록 빨라지며 최대 속도는 초당 600 게임 화면 픽셀입니다. 대각선 속도를 정규화하고 프레임 시간으로 이동량을 계산합니다. 커서가 중앙/맵 밖으로 이동하거나 창의 포커스를 잃으면 정지합니다. 마우스/터치 드래그도 지원합니다. 드래그 중에는 가장자리 이동을 일시 중단하고, 놓으면 마지막 이동 속도로 관성이 이어지며 지수 감쇠합니다. 멈춘 상태로 100ms 이상 기다렸다 놓으면 관성을 시작하지 않습니다. 관성 중 맵을 누르는 즉시 속도를 0으로 만들고, 클릭만 한 경우 정지 상태를 유지합니다. 맵 경계, 포커스 상실, 포인터 취소, 확대/중심 복귀 조작도 관성을 정지시킵니다.

휠/버튼 확대(0.5~3배), 중심 복귀를 지원합니다. 카메라 중심을 맵의 유효 WORLD 범위 안으로 제한합니다. 맵 모서리에서 화면에 배경이 보일 수 있습니다. 초기 카메라는 맵 중앙을 봅니다. 저장, 알림, PWA 및 실제 시드 주입은 아직 구현하지 않았습니다.

맵 중앙에서 생성되는 임시 캐릭터 하나는 휴식(1~5초)과 무작위 목적지 이동(2~10타일)을 반복합니다. 속도는 월드 기준 초당 1.2타일입니다. WanderBehavior가 모델 상태와 WORLD 위치를 갱신하고 Renderer가 위치, 깊이, 스프라이트를 동기화합니다. 이동 벡터를 투영한 화면 방향으로 8방향 이미지를 매칭하며 휴식 시 N/NE/NW 이동 뒤에는 후면(N), S/SE/SW 이동 뒤에는 정면(S)으로 정지합니다. E/W 이동 뒤에는 가장 최근의 정면·후면 구분을 유지하며 초기 기본값은 정면입니다. 카메라와 독립적으로 맵 전체에서 시뮬레이션하고 맵 경계를 지킵니다. 탭이 숨겨지면 시뮬레이션을 일시 정지합니다. 충돌/길찾기/저장은 아직 없습니다. 한 개체의 이동 방향에 따라 기존 8개 이미지를 전환합니다. 휴식 시 직전 정면·후면 계열에 따라 S 또는 N 이미지로 정지하고 이동 시 같은 이미지에 작은 흔들림을 적용합니다. 실제 걷기 프레임 애니메이션은 추후 교체합니다. 실제 다마고치 시드와는 별개입니다. 교체 규격은 ASSET_GUIDE.md를 따릅니다.

캐릭터 마우스 오버 시 프로필 말풍선을 표시합니다. 이름, 도착 후 경과 시간(시간/분), 유형, 세대를 표시하며 카메라 좌표와 CSS 크기를 반영해 캐릭터를 가리킵니다. 드래그 또는 커서 이탈 시 숨기며 위쪽 공간이 부족하면 아래쪽으로 표시합니다.

프로필의 세대 아래 행동 행에서 현재 이동/휴식 상태를 실시간 표시합니다. 캐릭터 아래 라벨은 프로필 이름을 표시하며 프로필이 없으면 개체 ID를 사용합니다.
